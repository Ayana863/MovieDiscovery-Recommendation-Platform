CineScope – Movie Discovery Platform
------------------------------------

CineScope is a modern, responsive movie discovery web application built for movie lovers. Users can explore trending and upcoming movies, browse by genre, manage favorites and watch history, and share their own reviews with star ratings.

Features
--------
*Trending ,Popular,TopRated and Upcoming Movies.
*Browse Movies by Genre.
*Favorites Management.
*Watch History.
*User Reviews with Star Rating.
*Persistent Data using LocalStorage.
*Fully Responsive UI.

Tech Stack
----------
*Frontend: React.js.
*State Management: Redux Toolkit.
*Styling: Tailwind CSS.
*Icons: React Icons.
*API: TMDB (The Movie Database).
*Storage: LocalStorage.
*Login / Logout functionality supported.
